# Project Learnings

- Pri požiadavke na osobnú stránku („About Me“ / portfólio), ktorá má ukázať grafickú a dizajnovú úroveň autora, prezentuj túto schopnosť priamo kvalitou samotného dizajnu stránky (typografiou, kompozíciou, paletou, zmysluplnými animáciami a vizuálnymi náhľadmi projektov) — nikdy nepridávaj meta-sekcie, kalibrátory rádiusov ani sebareferenčné vysvetľovanie CSS pravidiel.
- Vo verejnom portfóliu ani na osobných stránkach nikdy priamo neuvádzaj interné názvy firemných projektov, interné skratky systémov ani názvy klientov z pracovného GitLabu; komerčnú prácu vždy opíš všeobecne cez doménu, architektúru a použité technológie.
- Na dizajnovej „About Me“ a portfólio stránke sa vyhýbaj stenám textu a dlhým odsekom — používaj výhradne stručný mikro-copy (5–8 slovné nadpisy, jednovetové popisy max. 12–15 slov, číselné metriky a štítky) a nechaj hovoriť interaktívne vizuálne karty, bento mriežku a animované náhľady.
